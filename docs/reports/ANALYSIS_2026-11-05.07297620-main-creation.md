This card's last saved public ISD memory snapshot, after cleanup on October 28,
reported 119,940 persistent and 3,750 volatile bytes, tag 81 = 1. Those values

stand in for current counters, a largest allocatable block, or an installation
transaction budget. A fresh read-only FF21 snapshot is the next smallest useful
resource observation before considering an instrumented constructor experiment.
It can distinguish low reported resources from nominal reported availability;
it cannot localize a failing constructor operation.
