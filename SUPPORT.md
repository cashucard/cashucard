# Getting help

Cashu Card is an experimental open source project. Help comes from its
maintainers and community, on a best-effort basis.

- **Questions and ideas:** [GitHub Discussions](https://github.com/cashucard/cashucard/discussions)
  on cashucard/cashucard. Questions about the protocol, the applet, the client
  library and the tools all go there.
- **Bugs:** [open an issue](https://github.com/cashucard/cashucard/issues/new/choose).
- **The Cashu Card Provisioner app or an ops.cashucard.org account:** email
  [support@cashucard.org](mailto:support@cashucard.org), or see
  [cashucard.org/support](https://cashucard.org/support).
- **Vulnerabilities:** report them privately, as [SECURITY.md](SECURITY.md) describes.
- **Conduct:** [conduct@cashucard.org](mailto:conduct@cashucard.org), as the
  [code of conduct](CODE_OF_CONDUCT.md) describes.
- **Protocol changes:** propose them in [cashucard/nut](https://github.com/cashucard/nut).
- **A card from an issuer or a wallet app:** ask the issuer or the app's makers
  first; they run the card program and the app.
